# 문서 보관소

이 디렉터리는 삭제하면 맥락을 잃지만 현재 계약으로 사용하면 안 되는 자료를
보존합니다.

- `evaluation/`: PR #18 이전 평가 결과와 골든셋 v1 보고서
- `integration/`: 완료된 브랜치·PR 리뷰와 통합 판단 기록
- `handovers/`: 완료된 담당자 지시서와 팀 통합 계획
- `planning/`: 현재 코드보다 이전 시점의 로드맵
- `proposals/`: 구현 완료 또는 대체된 변경 제안서

보관 문서의 브랜치명·SHA·수치·경로는 당시 기록입니다. 현재 상태 확인에는
[상위 문서 인덱스](../README.md)를 사용합니다.
