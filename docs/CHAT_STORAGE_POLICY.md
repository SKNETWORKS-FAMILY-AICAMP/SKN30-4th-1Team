# 개인 대화 저장 정책

## 원칙

PaiM은 프로젝트 지식과 개인 대화를 분리한다.

- 프로젝트 자료, 저장소, 결정, 액션, 이슈, 리스크는 서버에 저장하며 프로젝트 구성원이 공유한다.
- 채팅 제목, 질문, 답변, 초안, 최근 대화 문맥은 데스크톱의 계정·서버별 로컬 저장소에만 보관한다.
- 다른 기기로 개인 대화를 자동 동기화하지 않는다.

## 질의 처리

데스크톱은 `POST /api/v1/projects/{project_id}/query`에 현재 질문과 제한된 최근 대화를
전달한다. 백엔드는 답변을 만들기 위해 이를 처리하지만 `chat_sessions`,
`chat_messages`, `chat_summaries`에 저장하지 않는다.

질문과 대화 본문은 애플리케이션 로그와 오류 로그에도 기록하지 않는다. 설정된 외부 LLM
제공자에게 전달되는 데이터의 처리는 해당 제공자의 정책을 따른다.

## 서버에 남는 사용자 관련 데이터

서버 저장은 서비스 운영과 프로젝트 협업에 필요한 범위로 제한한다.

- 계정: 사용자 ID, 이메일, 이름, 비밀번호 해시, 가입 시각
- 권한: 프로젝트 소유자, 멤버십, 역할
- 감사·용량: 업로드 사용자, 제안 처리 사용자, 업로드 크기와 처리 상태
- 공유 프로젝트 데이터: 프로젝트명, 업로드 자료, 연결 저장소, 추출된 프로젝트 메모리

채팅방 제목과 대화 본문은 위 범위에 포함하지 않는다.

## 레거시 세션 API

`/api/v1/projects/{project_id}/sessions/*`는 구형 클라이언트 호환을 위해 당분간 유지하지만
폐기 예정이다. 새 데스크톱은 이 API를 호출하지 않는다. 기존 서버 세션 데이터는 사용자별
삭제 절차와 롤백 기간을 마련한 뒤 별도 마이그레이션에서 정리한다.

## 로컬 데이터 보호 후속 과제

현재 WebView 저장소에 보관되는 대화는 후속 작업에서 앱 전용 암호화 저장소로 옮긴다.
암호화 키는 운영체제 보안 저장소에 두고, 전체 로컬 대화 삭제와 선택적 내보내기 기능을
제공하는 것을 목표로 한다.
