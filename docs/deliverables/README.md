# 필수 산출물 작업 공간

최종 제출본은 기능 동결 후 이 디렉터리에서 관리합니다.

| 산출물 | 의미 | 현재 참고 자료 |
| --- | --- | --- |
| 요구사항 정의서 | 사용자·시스템 요구사항, 범위, 우선순위와 수용 기준 | [제품 README](../../README.md), [API 명세](../API_명세서.md) |
| 화면설계서 | 화면별 목적, 상태, 전환, 입력·오류·권한 규칙 | `desktop/` 구현과 프론트엔드 핸드오버 |
| 시스템 구성도 | 데스크톱·API·MySQL·Chroma·외부 서비스·배포 경계 | [아키텍처](../ARCHITECTURE.md), [기존 HTML 초안](drafts/3_SYSTEM_ARCHITECTURE.html) |
| 테스트 계획 및 결과 보고서 | 범위·환경·케이스·기대 결과와 실제 결과·잔여 결함 | [검증 보고서](../reports/validation/) |

`drafts/`의 기존 자료는 최신 `main`과 실제 배포 E2E 결과를 반영해 갱신한 뒤
최종본으로 승격합니다.
