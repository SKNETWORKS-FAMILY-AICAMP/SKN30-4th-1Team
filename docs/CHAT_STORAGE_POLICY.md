# 개인 대화 저장 정책

## 원칙

PaiM은 공유 프로젝트 지식과 개인 대화를 분리한다.

- 프로젝트 자료, 저장소, 결정, 액션, 이슈, 리스크는 서버에 저장한다.
- 채팅 제목, 질문, 답변, 초안과 최근 대화 문맥은 계정·서버별 데스크톱 로컬 저장소에만 보관한다.
- 개인 대화는 다른 기기로 자동 동기화하지 않는다.

## 질의 처리

데스크톱은 `POST /api/v1/projects/{project_id}/query`에 현재 질문과 제한된 최근 대화를
요청 문맥으로 전달한다. 백엔드는 답변 생성 중에만 이를 사용하고 `chat_sessions`,
`chat_messages`, `chat_summaries`에는 저장하지 않는다.

## 레거시 세션 API

`/api/v1/projects/{project_id}/sessions/*`는 구형 클라이언트 호환을 위해 유지하지만
OpenAPI에서 deprecated로 표시한다. 현재 데스크톱은 이 API를 호출하지 않는다.
기존 서버 세션 데이터 정리는 별도 마이그레이션과 롤백 계획을 마련한 뒤 수행한다.

## 로컬 저장 한계

현재 대화는 WebView localStorage에 저장된다. 앱 데이터 삭제나 로컬 프로필 손상 시
복구되지 않으며, 운영체제 보안 저장소 기반 암호화와 내보내기 기능은 후속 범위다.
